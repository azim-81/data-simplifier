# Data Simplifier

A small Python project for cleaning and exploring CSV and Excel files.

I built this as a practical project while learning Python, Pandas and data analysis.

## Features

- Read CSV and Excel files
- Show rows, columns, missing cells and duplicates
- Show column types and unique values
- Tidy column names
- Remove completely empty rows and columns
- Remove duplicate rows
- Show before/after results
- Make simple charts
- Download the cleaned CSV

## Technologies

Python, Pandas, Streamlit, Plotly and OpenPyXL.

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project status

This is a learning project, not a production data-cleaning system. The cleaning rules are intentionally simple and the output should be checked by the user.

AI tools were used as a coding assistant during development. I tested and modified the application and use the project to learn the underlying Python and data-processing concepts.
